# Expectation, Variance, Covariance

> Part of [Maths-for-ML](../Readme.md)

## Goals
- [ ] Expectation `E[X]`, linearity, LOTUS
- [ ] Variance `Var(X) = E[X^2] - E[X]^2`, std, correlation
- [ ] Covariance matrices, independence vs uncorrelated

## Key formulas
- `Var(X) = E[(X - μ)^2]`
- `Cov(X,Y) = E[(X-μx)(Y-μy)]`
