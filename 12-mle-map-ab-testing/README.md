# MLE, MAP, A/B Testing

> Part of [Maths-for-ML](../Readme.md)

## Goals
- [ ] MLE: `θ* = argmax log P(data|θ)`
- [ ] MAP: `θ* = argmax [log P(data|θ) + log P(θ)]`, regularization as prior
- [ ] A/B testing: conversion rates, significance, sample size intuition

## Key formulas
- MLE: maximize log-likelihood
- MAP: MLE + log-prior
